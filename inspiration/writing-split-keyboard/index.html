一把为长时间写作设计的分体键盘

把分体结构、静音轴和一块小屏幕放在一起，做成更适合写作而不是游戏的键盘。

洛洛一@luoyi · 3 小时前
Read only

项目背景
我每天写作六到八小时，手腕和肩颈经常不舒服。市面上很多分体键盘是为键盘爱好者调试和游戏设计的，对写作者并不友好。

想解决的问题
在不增加复杂配置的前提下，让分体键盘更容易上手，并把写作时最常用的操作放到更自然的位置。

实现思路
- 左右分体、低前高，默认配列接近普通键盘
- 静音轴体与轻量段落感，适合长时间输入
- 小屏幕显示当前文档字数、时间和今日输入目标
- 支持一键切换两台设备，减少写作时的切换成本
- 开源外壳与固件，提供一套不需要编程的默认配置

想找的伙伴
结构设计、固件开发、长期写作者参与试用。
